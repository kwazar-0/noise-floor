## ЧТО ИЗМЕНИЛОСЬ

### **Новая логика:**
1. **Пролог:** контекст 90-х культов → читатель понимает эпоху
2. **Главы 1–3:** Оля уязвима (мама) → попадает в **безымянную секту** (не Орден!)
3. **Главы 4–5:** Сбегает → бандиты → Марго спасает
4. **Глава 6:** Подписывает контракт → **входит в Орден** (институт, не психоз)
5. **Главы 7–19:** Орден, тренировки, операции (текущие главы 5–17, перенумерованы)
6. **Главы 20–27:** Орбита (текущие orbita 18–25, перенумерованы)

### **Ключевые различия:**
- **Анонимная секта (главы 2–3):** капсула-обман, Учитель-шарлатан, вдох на четыре, психоз
- **Орден (главы 6+):** контракт, институт, калибровка, Марго/Артур, протокол, не психоз

### **Что даёт новая структура:**
1. **Понятный вход:** мама обесценивает → Оля ищет спасения → попадает в секту
2. **Контекст эпохи:** Белое братство, Аум Синрикё → читатель понимает 90-е
3. **Ясная логика:** секта (обман) → бегство → бандиты (угроза) → Орден (институт)
4. **Разделение:** секта ≠ Орден. Читатель не путает.
5. **Крючок:** две точки напряжения (мама + бандиты) вместо одной абстракции
