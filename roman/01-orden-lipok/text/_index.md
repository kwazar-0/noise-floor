## КЛЮЧЕВЫЕ ОТЛИЧИЯ

### **Безымянная секта (главы 2–3) ≠ Орден (главы 6+)**

| Секта | Орден |
|-------|-------|
| Психоз, капсулы-обман | Институт, протокол |
| Учитель-шарлатан | Артур/Марго-операторы |
| Вдох на четыре | Калибровка |
| Источник = спирт | Контракт = документ |
| Оля бежит | Оля подписывает |
