# Структура сериала — Орден Липок

**Формат**: Limited series / Mini-series  
**Жанр**: Psychological spy thriller, noir  
**Эпизодов**: 8–10 (по 45–60 минут)  
**Платформа**: Streaming (Netflix/HBO style)  
**Язык**: Русский + украинский  
**Период**: 1992–1993, Киев + орбита

## Общая структура арки

### Акт I (Эп. 1–2): Вербовка
Оля сбегает из ячейки → попадает в салон Марго. Психологический контраст: cult → bourgeois cult.

### Акт II (Эп. 3–5): Обучение и машина
Школа гетери → СИТО подвал → понимание схемы. Оля становится фильтром.

### Акт III (Эп. 6–7): Кризис и трансформация
Тайный суд, моральная ломка → попытка побега → принятие. Оля больше не студентка.

### Акт IV (Эп. 8): Орбита
Машина больше Киева. Имя уже не её. Глаза открыты.

---

## Тематические нити через сезон

1. **Улика как мотив**: капсула (эп1) → студенческий → досье → папка → флажок → дело без обложки (эп7)
2. **Лампа как проверка**: Оля проверяет лампу перед сном — ритуал контроля, который становится бессмысленным
3. **«Все ок»**: гудок с Петром редеет, последний в эп.4, потом мёртв
4. **Четыре комнаты**: постепенно накапливаются, в эп.7 sound design — все четыре слоя звука одновременно (жалюзи, кулеры, мазут, паркет)
5. **Глаза**: «закрыть глаза = отдать» → в финале глаза открыты

## Casting note

Сериал требует **strong ensemble cast**:
- Оля: молодая актриса, способна держать экран без диалога (много молчаливых сцен)
- Марго: mature elegance, ballet background предпочтительно
- Инженер: haunted technical mind, может играть усталость
- Софья: commanding elderly actress
- Варяг: working-class gravitas

Украинский/русский билингвизм у актёров обязателен.

## Production note

- **Период**: 1990s reconstruction (костюмы, машины, интерьеры)
- **Локации**: Киев (или Украина/Восточная Европа для съёмки) + международные (Турция, Австрия, Израиль, Гонконг можно частично в павильонах)
- **Tone**: cold, clinical, Fincher-esque lighting
- **Камера**: close-ups, handheld для tension, static для institutions
- **Музыка**: minimal, electronic undertones, Ukrainian folk motifs деконструированы
