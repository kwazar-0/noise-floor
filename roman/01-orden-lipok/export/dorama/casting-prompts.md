# Кастинг — AI Generation Prompts

Промпты для генерации персонажей (AI-дорама) или референсов для реального кастинга.

**Стиль**: photorealistic, cinematic lighting, 1990s period drama aesthetic, Eastern European faces, natural no-makeup looks for realism.

## Технические параметры AI-генерации

### Для видео (AI-дорама с генерированными персонажами)

**Consistency требования**:
1. **Character reference lock**: первый generated image становится reference для всех сцен этого персонажа
2. **Midjourney**: использовать `--cref <URL>` для consistency
3. **Stable Diffusion**: train LoRA на лице персонажа
4. **Runway/Pika**: использовать character-consistent video generation

**Lighting consistency**:
- Interior salon (Липки): amber chandelier, warm 3200K
- СИТО basement: green phosphor CRT glow, cold
- Exterior Kyiv: overcast gray, winter 5600K
- Орбита: varies by location

**Camera**:
- Close-ups: 85mm equivalent
- Medium shots: 50mm
- Wide establishing: 24mm
- Handheld feel для tension scenes

### Для реального кастинга

Эти промпты использовать как **visual reference** для casting director:
- Распечатать AI-generated faces
- «Мы ищем похожий type» (не точное совпадение)
- Приоритет: acting ability > похожесть на промпт

## Дублирование vs субтитры

- **Оригинальная озвучка**: русский + украинский (как написано)
- **Для международного**: английские субтитры, НЕ дублировать (сохранить аутентичность языковой смеси)
- **Украинский рынок**: без субтитров (билингвизм понятен)
- **Русский рынок**: украинские фразы с русскими субтитрами (опционально)

## Casting budget note

Если AI-generated персонажи:
- Нулевая стоимость актёров
- Высокая стоимость AI video generation + consistency tech
- Voice actors для озвучки (дешевле live actors, но требует качество)

Если live actors:
- Ukrainian/Russian actors дешевле Hollywood
- Съёмка в Украине/Восточной Европе экономична
- Требуется period vehicles, costumes (budget line item)
