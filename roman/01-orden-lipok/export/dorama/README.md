## Ключевые творческие элементы

### Tone
Psychological noir thriller, cold, Fincher/Tarkovsky влияние, slow burn, no action beats, intelligence-driven, moral ambiguity.

### Visual style
- Desaturated palette
- Practical lighting (harsh institutions, intimate single sources)
- 2.39:1 scope
- Textures: worn, rain, condensation, fabric, dust
- Close-ups as evidence: capsule, documents, stamps, hands

### Sound
- Minimal score (electronic undertones)
- Diegetic sound emphasized (radiator hum, CRT monitors, rain)
- Silence as weapon
- Bilingual dialogue (Russian + Ukrainian, no translation)

### Themes
- Вербовка как фильтр
- Учреждение начинается с боли, не с устава
- Улика раньше приговора
- Тайный суд без мандата
- Имя уже не её — глаза открыты

## Production pipeline

### Pre-production
1. **Script breakdowns**: 8 episodes, full shooting scripts (используй template из e01-opening)
2. **Casting**: See `casting-prompts.md`
3. **Location scout**: Kyiv + international (или decision для CGI)
4. **Set builds**: СИТО, Salon (key sets)
5. **Costume design**: 1990s period accurate
6. **Prop fabrication**: Hero props list in `production-design.md`

### Production
1. **Principal photography**: 20–24 weeks (live-action) или 8–12 weeks (AI with post)
2. **Unit photography**: Establishing shots, B-roll
3. **Animal wrangling**: Parrot (if live)
4. **On-set data**: Script supervisor для continuity (critical for multi-episode)

### Post-production
1. **Editing**: Assembly → rough cut → fine cut
2. **VFX**: Minimal (remove modern elements, CRT content, weather enhancement)
3. **Color grade**: Desaturated LUT, per-location palette
4. **Sound design**: See `production-design.md` sound section
5. **Score**: Minimal electronic (composer: Jóhann Jóhannsson style)
6. **ADR**: Bilingual loop group
7. **Mix**: 5.1 + Atmos
8. **Mastering**: 4K HDR master, 1080p SDR deliverables
9. **Subtitles**: EN, UK, RU

## Appendix: AI Tools Reference (2026)

**Character generation**:
- Midjourney v6+ with `--cref` (best consistency)
- Stable Diffusion XL + LoRA training (open-source)
- Flux (emerging, good faces)

**Video generation**:
- Runway Gen-3 Turbo (fast, short clips)
- Pika 2.0 (good for motion)
- Kling AI (longer sequences, improving)
- Sora (if available, best quality but expensive)

**Voice**:
- ElevenLabs (multilingual, quality)
- Professional ADR studio (preferred для bilingual authenticity)

**Post**:
- DaVinci Resolve (color + edit)
- After Effects (compositing)
- Pro Tools (sound mix)

**Consistency tech**:
- Character LoRA training (Stable Diffusion)
- Face swap post-fix (Roop, DeepFaceLab) если AI drift
