# Печатное издание — Орден Липок

Готовый пакет для публикации на портале.

## Содержание

- **`metadata.md`** — метаданные, аннотация, структура книги
- **`illustration-prompts.md`** — 26 промптов (обложка + 25 глав)
- **`text/core/`** — 17 глав ядра (`glava-01.md` – `glava-17.md`)
- **`text/orbit/`** — 8 глав орбиты (`18.md` – `25.md`)

## Структура издания

### Часть I: Ячейка (главы 1–4)
Капсула. Побег. Москвич. ДК. Салон Липок.

### Часть II: Салон (главы 5–8)
Школа гетери. Досье. Деканат. Кофе комитета.

### Часть III: СИТО (главы 9–13)
Гаражи. Подвал фосфора. Шулявка. Грушевського. Мундштук.

### Часть IV: Побег (главы 14–17)
Узел. Тайный суд. Засов. Кода.

### Орбита (главы 18–25)
Хавала. Карина. Вена. Архив. Циля. Тарик. Лот. Линь.

## Формат публикации

Рекомендуется:
- Обложка по промпту (noir, капсула в руке)
- Иллюстрация к каждой главе (чёрно-белые или muted color)
- Типографика: классическая книжная вёрстка, serif для прозы
- Украинские диалоги курсивом или без перевода
- Эпиграфов нет, предисловие опционально

## Объём

~25 000 слов (17 ядро + 8 орбита)  
~2500 строк прозы  
Формат A5 или цифровой PDF/ePub

## Лицензия

Определяется автором. Материал готов к публикации.
