## Правила камеры

- Ядро (1–19): Оля в кадре или её POV. Не телеметрия института.
- Учитель культа: **лица крупно нет** (затылок, кисти, серый пиджак, проём). Паспорт: `setings/geroy-psihotip/uchitel-kult.md`.
- Ципао — Мадам Линь (`glava-27`), никогда Марго.
- Суржик Ніни / Петра / Седого — в баллонах без перевода (сноска внизу страницы ок).
- В caption **не** класть формулы склада: «учреждение начинается», «это фильтр», «ноги папки», «не X, а Y».
- Секта (гл. 2–3) ≠ Орден (каракуль гл. 5, имя гл. 6, документ гл. 8). Разный свет, разная ткань.

## Рекомендации мангаке

1. Monster / 20th Century Boys — психология лиц; не anime-cute.
2. Текстуры: лак ногтей, клеёнка, бархат, бетон, дождь, воск паркета.
3. Молчаливые панели обязательны.
4. Руки крупно: трубка, аркуш, капсула, ручка контракта, чашка.
5. Архитектура: Київ 1992, worn, не чистая Япония 90-х в декорации.
6. Оля на дне — `ref-olya-01-student` / культ `ref-olya-02-cult-adept` (**5 ночей, не лагерь смерти**).
