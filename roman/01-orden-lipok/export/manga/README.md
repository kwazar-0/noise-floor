# Манга-адаптация — Орден Липок

Пакет для производства манги (seinen, психологический триллер).

---

## Содержание

- **`character-designs.md`** — дизайны 16 персонажей с промптами (Оля, Марго, Инженер, Софья, Варяг и др.)
- **`locations-reference.md`** — референсы 20+ локаций с промптами (салон, СИТО, хавала, чайный дом и др.)
- **`scene-breakdown-chapter-01.md`** — полный сценарий главы 1 (~18–22 стр, 100+ панелей)
- **`chapter-templates/`** — шаблоны для остальных 24 глав (создать отдельно)

---

## Формат манги

**Жанр**: seinen (взрослая аудитория)  
**Стиль**: реалистичная манга, noir/psychological thriller  
**Референсы**: Naoki Urasawa (Monster, 20th Century Boys), Jiro Taniguchi, Koike/Kojima  
**Тон**: серьёзный, без fanservice, grounded

**Объём**:
- 25 глав (17 core + 8 orbit)
- ~15–25 страниц на главу
- Итого: ~400–600 страниц манги

**Формат страниц**:
- B5 или A5 (японский стандарт)
- Чёрно-белая с screentone ИЛИ muted color (цифровая)
- Чтение справа-налево (японский стиль) или слева-направо (западный)

## Ключевые особенности адаптации

### 1. Визуальные якоря
Каждая глава имеет **key visual** (обложка главы):
- Глава 1: Капсула в кулаке
- Глава 4: Жако в клетке, хрусталь
- Глава 10: Зелёный фосфор мониторов
- Глава 15: Варяг с коньяком у карты
- Глава 17: Босые ноги на паркете, четыре комнаты в ухе
- Глава 25: Гайвань, ципао сапфир

### 2. Языковые слои
- **Русский**: основной нарратив, caption boxes
- **Украинский**: диалоги Нины, Петра, бытовой Киев — оставить без перевода в баллонах (или сноски)
- **SFX**: японские звуки (ザアアア для дождя, ゴゴゴ для tension) или русифицировать

### 3. Ритм панелей
- **Slow burn**: claustrophobic tight panels для психологии (ячейка, СИТО подвал)
- **Action beats**: wide cinematic для побега, дождя, города
- **Silence panels**: пустые или minimal для пауз (Инженер не отвечает, Варяг молчит)

### 4. Камера = Оля
В ядре (1–17) почти всегда **POV Оли** или она в кадре. Орбита (18–25) может shift на других (Карина, Инженер в Гонконге).

### 5. Символы-рефрены
- **Капсула** (глава 1, возвращается в памяти)
- **Монета Инженера** (крутит в пальцах)
- **Прядь Марго** (справа)
- **Жако крик** (вместо телефона)
- **Четыре комнаты** (жалюзи, фосфор, переноска, паркет)

## Производственный pipeline

### Этап 1: Pre-production
- [x] Дизайн персонажей
- [x] Референсы локаций
- [x] Сценарий главы 1 (пример)
- [ ] Сценарии глав 2–25 (по шаблону ch01)

### Этап 2: Раскадровка (Name/絵コンテ)
- Художник делает rough sketches панелей по сценарию
- Утверждается composition, flow, page turns

### Этап 3: Pencils & Inks
- Чистовые карандаши
- Чернила (или цифровой ink)

### Этап 4: Screentone/Color
- Если ч/б: screentone для текстур, теней, атмосферы
- Если цветная: muted palette (см. locations reference)

### Этап 5: Lettering
- Баллоны диалогов
- Caption boxes
- SFX
- Украинский текст (шрифт, возможно курсив)

### Этап 6: Publish
- Digital (web/app) или print

## Рекомендации для мангаки

1. **Читать референсы**: Monster (Urasawa) для психологии, 20th Century Boys для conspiracy, Gunslinger Girl для девушки в машине
2. **Держать realism**: лица европейские, пропорции realistic (не anime cute)
3. **Текстуры важны**: ткань (бархат, кофта), дерево, бетон, дождь
4. **Silence работает**: не бояться панелей без диалога
5. **Руки в кадре**: часто крупным планом (держат капсулу, чашку, документ)
6. **Глаза**: не огромные; усталость, бессонница показывать реалистично
7. **Архитектура**: 1990s Eastern Europe — worn, institutional, не чистая

## Альтернативные форматы

- **Webtoon** (вертикальный scroll): потребует редизайн панелей
- **Graphic novel** (западный формат): слева-направо, больше текста на страницу
- **Анимация**: этот пакет можно использовать как storyboard для аниме-адаптации

## AI-инструменты для производства

Если используются AI для ассистирования:

### Character consistency
- Используйте **character-designs.md** промпты в Midjourney/SD с `--cref` для consistency
- Train LoRA на лица персонажей для Stable Diffusion

### Backgrounds
- **locations-reference.md** промпты для базовых фонов
- Постобработка в Photoshop/Clip Studio для финальных деталей

### Panels
- AI может генерировать keyframes (важные панели)
- Inking и composition всё равно требуют художника

### Не AI
- Эмоции лиц, body language
- Composition панелей
- Flow страниц
- Финальный ink
