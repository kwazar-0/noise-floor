# Предмет-протокол (`gl1` → якорь, не глобус)

Хавала склада строится на вещи без имени: половинка карты, код, честное слово, жёсткий аргумент периметра. Том 01 **не открывает** лавку у Босфора. Берёт закон: **квитанция — предмет, не расписка в журнале**.

Имена не пишут. Репутация пишет. Если на столе появляется гербовая бумага как салют оператора — это ошибка `gl1/text-009`.

## Якоря ядра (уже в паспортах / локациях)

| Предмет | Кто держит | Что квитирует |
| --- | --- | --- |
| Папка / машинка | Полина, референтка, Оля как ноги | бумага раньше кабинета |
| Плёнка / бумажки с клеёнки | Оля → Полина / СИТО | имена, которые источник нёс сам |
| Распечатка без папки | Инженер Софье | спор каст: лог vs досье |
| Флажок на кривой карте | Варяг | адрес, который схема ещё зовёт фильтром |
| Медная монета / латунная гильза | Инженер | чётки атеиста; не транзит в Стамбул |
| Первая заливка чая (омовение) | Софья | вход в учёт; гость пьёт вторую |
| Камень го / шар | Софья | правило против чуда |
| Студенческий | Оля | мёртвая фотография прошлого хозяина |
| Конверт деканата | Ирина Петровна vs Орден | штамп старого мира |
| Каракуль / перчатка | Марго | юрисдикция зала, не ствол |

## Вещь-вход для старой кости

Склад: супница из архива, портсигар Циле, уважение вместо папки на стол.  
Канон: тот же жест **внутри Киева**. Вернуть предмет, который институт когда-то изъял; посадить ниже; не повышать голос. Не рейс в Тель-Авив.
