## Строки без отдельного файла

- Культ → Оля: ночь, источник. Учитель без лица. Бунт глазами и ботинками.
- Ніна / Петро → Оля: сором; гудок. Справжній батько vs Віктор-мрія.
- Ирина Петровна → штамп. Конверт.
- Орден → чиновник: гарантия будущего, не взятка. Смазка коридора, не трон.
- Орден → идеалист (если папка): камертон / внешнее управление. Тип, не вывеска.
- Варяг + Марат + Доктор: периметр не из одного человека.

История Оли и матери: не месть нищете. Показная победа второго источника; голос уже не свой.
