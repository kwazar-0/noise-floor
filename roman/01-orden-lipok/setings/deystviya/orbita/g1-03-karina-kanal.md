# g1-03 Стамбул: канал Карины

- Орбита. Склад: `gl1/text-002.md` §1.
- Паспорта: Карина, Марго (подбор, не ствол), хор «люди брокера». Халид ещё может не иметь имени.

## Такты
1. Потоки через лавки выросли. Нужен рот, который входит без чемодана.
2. Марго ставит переводчицу, не бойца. Легенда: экспортёр антиквариата / курсы османистики.
3. Три недели до аудиенции. Дипломатическое молчание.
4. Нефтедоллар ↔ квота металла. Канал замкнут. Карины может уже не быть в комнате.

## Выход
Женский рот эффективнее бригады. Не произносить это гимном. Доказать тактом 3–4.

## Запрет
Том 01. Мата Хари вслух. Оля вместо Карины.
