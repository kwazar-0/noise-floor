# Цель Ордена (том 01)

**Снаружи (заказ Софьи):** объекты из старых папок снова под контролем. Влияние через окружение — секретариат, клуб, кухня — не через трибуну. Дальний горизонт: процессы страны, потом чужой берег. В томе 01 горизонт не брать в кадр как победу.

**Рабочий масштаб ядра:** бумага, отгрузка и живой рот совпали **до** площади. Политик орёт. Коридор уже решил.

Из `gl1/text-099.md` без глобуса: **не сесть во главе стола**. Стать серой деталью, без которой казённый стол скрипит. Для купола — копейка. Для Ордена — точка опоры. Метод: `../svyazi/kontur-blagodarnosti.md`.

Как это слышат станки (не сводить в один лозунг в прозе):

- **Софья Карловна.** Папки не должны умереть вместе с вывеской. Пенсия без доски неприлична. Объект из архива — актив. Шантаж в её лексике — «учёт» и «гарантия будущего».
- **Марго.** Клуб кормит и ловит. Грех платный. Подшефная думает, что держит салон; держит задания по папке.
- **Инженер.** Деньги / товар / информация. Речь врёт. Тоннаж — нет. Не нанимался «контролировать страну».
- **Варяг.** Стеречь своих и дверь. Седой — чужая касса. Тайное силовое — работа, не титр.

**Запрет цели в кадре:** «мы теневое правительство»; «развлекаюсь на пенсии»; гимн. Цель видна: папка раньше депутата, флажок, кивок «сами».
