# Цепь юрисдикций (не детектив)

Оля собирает не «убийцу», а **кто сейчас имеет право на её дыхание**. Кроки камери: `hronologiya.md` А. 1–17.

| Такт | Кто держит закон | Как это слышать |
| --- | --- | --- |
| Ячейка | хор / Учитель без лица | вдох на четыре; капсула |
| Улица | холод, нет хозяина | ботинки |
| Москвич | скаут, труба Седого | работа + куток |
| Гримерка | Иса (долг), Саня (точка) | застава |
| Каракуль | Марго | «идёшь со мной» |
| Антресоли | Марго + Полина как цех | интересно / ревность |
| Клеёнка | куратор ↔ источник | дочь + коридор |
| Деканат | конверт Ордена vs штамп кафедры | чужая кожа |
| Гараж | Варяг / Инженер | не садиться, не коньяк |
| СИТО | лог | тоннаж |
| Шулявка | Софья Карловна | «Ольга», задача |
| Грушевського | папка сети | ноги папки |
| Порог салона | оба полюса, рефери в отсутствии | чай и мундштук |
| Суд (IV) | Варяг произносит | нас не выбирали |

Читатель видит трубу раньше Оли. Напряжение — не тайна имени, а **зазор**: она ещё слышит все законы сразу.

Инженер собирает другую цепь: речь → отгрузка → флажок. Это не расследование преступления. Это ревизия входа.

Из `gl1`: учреждение — когда закон держит дыхание **без** носителя раны. Папка на Грушевського не обязана помнить вокзал Оли.
