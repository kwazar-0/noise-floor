## Запуск (том 01)

Софья Карловна (папки старой работы) включает подшефную Марго. Клуб на Липках — эскорт / разведка / стол с источником. Инженер — сходимость потоков. Бригада Варяга — периметр и тихая сила. Седой — враждебный низ, не соучредитель.

| Станок | Функция | Боль, которую перегоняет |
| --- | --- | --- |
| Софья Карловна | заказ, архив, объект из папки | пустая пенсия / мёртвая вывеска → учёт |
| Марго | клуб, влияние, тела | голод, стыд, «хочу жить» |
| Инженер | деньги, товар, информация | ложь речи → тоннаж |
| Варяг | дверь, поручение без вывески | Афган / «своих» → ключи |

Зазор: **Оля** (том 01) → незакрытая перекодировка (том 03). Не замазывать.

Снаружи: **обслуга купола**, затем — если Киев держит — чужой берег. Не копировать `gl1` в ядро.
