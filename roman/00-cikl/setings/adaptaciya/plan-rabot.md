## Принцип производства

Один конвейер на все носители:

```
проза  →  библия кадра  →  раскадровка  →  пилот  →  серия
              ↑
     лица / интерьеры / запреты
```

Манга, дорама и иллюстрации книги **делят** лица, локации, key visuals. Расходятся только ритм (панель / план / разворот).

Тома не смешивать в одном сезоне и в одном tankobon:

| Том | Регистр | Носитель-лидер | Чужой жанр |
|---|---|---|---|
| 01 | тело, 1992–93 | манга seinen + limited series | неон, «лихие 90-е» клип |
| 02 | математика, 2007–09 | графическая новелла / radio-drama экранов | толпа на бирже |
| 03 | калибровка, 2022 | techno-noir serial, 16 актов = 4×4 монтаж | супергерой, шесть неоновых мониторов |

## Команда (минимум)

Не штат студии на $16M. Ядро, которое может вырасти.

| Роль | Делает | Не делает |
|---|---|---|
| **Канон-редактор** | сверяет кадр с `text/` и паспортом | «улучшает» фабулу |
| **Хранитель лиц** | lock референсов, стадии Оли, запрет ципао | новые лица «для красоты» |
| **Манга-юнит** | breakdown → name → ink | титры института в caption |
| **Дорама-юнит** | beat sheet → shooting script | закадровый манифест |
| **Иллюстрации / Pages** | обложки глав, фон читалки | сюжетный кадр без файла прозы |
| **Звук** (с фазы C) | суржик, батарея, CRT, дождь | score, который объясняет мораль |

Креативный директор утверждает: key visual главы, пилот, палитру тома, stop-list.
