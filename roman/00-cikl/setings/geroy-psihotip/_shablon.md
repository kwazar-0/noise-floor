# Шаблон: персонаж (манга / дорама)

Файл: `имя.md`

## 1. Паспорт кадра
- Имя / позывной / как называют в титрах
- Возраст в томе (и как выглядит)
- Рост, тело, осанка, походка
- Лицо, волосы, глаза, рот, руки (руки снимать отдельно)
- Приметы: шрам, прядь, артрит, дёрганый глаз, дрожь

## 2. Костюм
- Базовый комплект
- Варианты: работа / ночь / дно / «маска элиты»
- Предмет-якорь (мундштук, планшет, студенческий, гильза)

## 3. Цвет и тон
- 2–3 цвета персонажа
- Манга: где чёрная плашка, где пустой белый
- Дорама: ключевой свет (янтарь / 4000 K / фосфор)

## 4. Голос и речь
- Тембр, громкость, пауза
- Словарь касты (не общий авторский бархат)
- Жест, который заменяет реплику

## 5. Психотип
- Чем дышит
- Чего боится, когда никто не смотрит
- Чем вербует / чем вербуется

## 6. Для раскадровки
- Три крупных плана (глаза / руки / предмет)
- Запрещённый кадр (что ломает персонажа в клише)
