# Цикл. Сквозные психотипы

Не дублировать тома. Здесь только типы, которые повторяются под разными именами.  
Паспорт тома пишется **до** связи и такта: `../osnova/sloi.md`.

| Тип | Функция | Маски |
| --- | --- | --- |
| Чёрный эмпат | читает дыру и ставит крючок | Марго (плоть, салон) → Эстер (комплаенс, 49-й этаж) |
| Архитектор | печатает боль в схему | Инженер / Guest_00 |
| Бракованный актив | недобитая перекодировка | Оля после культа → героиня у зеркала |
| Архивариус | фильтрует шлак, не души | Артур / СИТО |
| Холодный рассудок | карта, Го, досье | Софья Карловна (польск. / Коминтерн) |
| Силовой контур | руки без права на кабинет | Варяг |

Каста голоса (держать): макро-математика / ткань / ESG / null-route — не общий бархат автора.
