# Том 03. Герои и психотипы

Канон ядра:

- **Эстер Вайнштейн** — чёрный эмпат комплаенса. Материнский голос, ипотека, перекодировка. Не читать лекции; одна подмена понятий за раз.
- **Дэвид** — актив на выгорании. Не реквизит: одна конкретная мысль/цифра, которую у него забирают.
- **Голдер / Голдин** — null-route, «спасение» как клиника и новое лицо.
- **Героиня (безымянная, пока не сшита с Олей)** — К-ПТСР, деперсонализация, фантом в зеркале. Критика к фантому сохранена. Чёрный лебедь для Excel.
- **Илья** — промежуточное поколение, находит слой Blind Drop. Не суперхакер.

Клуб (Пендлтон, Штейн, Элеонора, Ву, Штерн) — касты, не визитки. Балтийская артель — не больше одной лодки в фокусе, пока не держится закон.
