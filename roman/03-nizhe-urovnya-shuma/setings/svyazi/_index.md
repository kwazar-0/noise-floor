# Том 03. Связи

Эстер → Дэвид: вербовка на истощении. Кокон, рационализация, шея, «умница».

Голдер → героиня: благодетель после культа/отчисления. Пластик, голос, контракт.

Эстер ↔ Марго (через цикл): узнавание метода, не встреча, пока не нужна сцена.

Балтика → Лондон: пакеты, не дружба. Манхэттен → Балтика: катер как уборка.

Героиня ↔ объект Tier-1: съём данных на пределе; фантом вмешивается в решение.
