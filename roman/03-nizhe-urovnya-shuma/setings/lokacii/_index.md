# Том 03. Локации

1. Кабинет Эстер, 49-й этаж — тёплый контур нового века.
2. Стерильные апартаменты / клиника Голдера — зеркало, 4000 K.
3. Стекловолокно в шхерах — одна единица флота, не четыре, пока не надо.
4. Резиновый баркас — статистика, которой дают номер.
5. Редакция как приёмник пакета — не OSINT-энциклопедия.

LoRa, RAG, Starlink — реквизит молчания, не витрина технологий.
