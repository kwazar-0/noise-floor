# Канал Blind Drop

## Функция
Единственное общее место. Не серверная из кино.

## Визуал
Чёрный фон. Ники. Время сессии. Курсор. Иногда «печатает / стёр».

## Сенсорика
Тишина комнат за экранами разная (капля / озеро / банка с пеплом) — монтировать звуком.

## Съёмка
Дорама: сплит 4. Манга: лента сообщений как вертикаль страницы.
