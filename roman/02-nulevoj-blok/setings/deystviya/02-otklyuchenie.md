# 02-02 Отключение Guest_00

- Канал. Все ники. Финал тома.

## Такты
1. Короткая строка: база скомпилирована. Первый блок запечатан.
2. «Меня здесь больше нет».
3. Ник гаснет. Не «offline» с анимацией — дыра в ленте.
4. Четыре комнаты: Липки, Киев, Цюрих, дача — экраны гаснут не синхронно.
5. Последний звук: не фанфары, а вентилятор / капля / озеро.

## Запрет
Лицо Сатоши. Титр «так родился биткоин».
