# Сцена из ленты

Сюжет не выдумывать. Сюжет уже есть: `roman/01-orden-lipok/setings/osnova/hronologiya.md`.  
Проза — `roman/01-orden-lipok/text/` (ядро `glava-NN.md`, орбита `orbita/NN.md`).  
Голос комнаты: `.cursorrules`. Слои: `roman/00-cikl/setings/osnova/sloi.md`.

## Один проход = одна сцена

1. Открыть хронологию. Взять **следующий незакрытый шаг** (нет файла прозы, или пользователь назвал номер). Не прыгать через дыру. Не тащить 18+ внутрь 1–17.
2. Собрать кухню **до** письма:
   - такт: `setings/deystviya/` или `deystviya/orbita/`
   - место: `setings/lokacii/`
   - тела в кадре: `geroy-psihotip/` (хор без паспорта — хор)
   - долг: `svyazi/` между теми, кто дышит в сцене
3. Если нет паспорта или связи — **сначала карточка**, не сцена. Не подставлять Олю вместо Карины, Марго в ципао, глобус в зиму ядра.
4. Писать **только** в `text/`. Карточки такта не копировать абзацами. Четыре удара спрятать в жесте.
5. **Объём — жёсткий.** Ядро `glava-*.md`: не меньше **90 строк** сплошной прозы (~1500–2500 слов). Ориентир: `glava-01.md`. Орбита: не меньше **60 строк**. Файл на 15–20 строк — бриф, сцена **не закрыта**. Не добавлять новых ходов фабулы: набирать длительность уже данного такта (ожидание, тело, погода, чужая речь, пауза). Один пункт кухни = несколько абзацев, не одно предложение.
6. Перед «готово»: `wc -l` по файлу. Ниже квоты — дописать. Не рапортовать коротыш.
7. Камера шага — из хронологии. Ядро: близкая третья Оли. Орбита: рот такта. Не телеметрия.
8. В текст не класть: список тактов, «запрет», «выход», подписи закона, припев «не X, а Y», сырой `gl*`.
9. Стоп после одного файла, если пользователь не сказал «пачку» / «акт». Кратко: шаг, строк, следующий на ленте.

## Что не автогенерировать

Фабулу с нуля. Синхрон Яффо в главах 1–12. Новые акты в обход хронологии. `/loop` по главам — жрёт стиль.
