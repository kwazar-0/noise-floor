#### 1A. Прийомний салон (PUBLIC) — ВЕРСІЯ 2.0 (OPULENT)
**Файли:** 
- `interiors/ref-interior-salon-margo-v2.png` — multiple angles (3 ракурси)
- `interiors/ref-interior-salon-margo-wide.png` — wide shot
- `interiors/ref-interior-salon-margo-detail.png` — close details

**Концепція:** Зимний палац + Montmartre bordello + Vegas casino

**Ключові елементи:**
- **Люстра:** МАСИВНА, сотні кришталів, позолочений каркас
- **Стіни:** Позолочені бароко молдинги від підлоги до стелі
- **Оксамит:** Червоний і золотий скрізь (штори, меблі)
- **Паркет:** Елочка з воском, дзеркально блищить
- **Колони:** Мармурові з позолотою (опціонально)
- **Жако:** В орнаментованій латунній клітці
- **Карта світу:** В масивній позолоченій рамі з маршрутами
- **Чайний сервіз:** Порцеляна з золотим візерунком
- **Меблі:** Бароко з червоним оксамитом і золотим тримом
- **Світло:** Тепле золоте від люстри + настінних світильників

**Атмосфера:**
- **ШОКУЮЧИЙ** контраст з нищим Києвом 1992
- Неможлива розкіш в голодному місті
- Портал не просто в Париж, а в Версаль / Петербург
- Психологічний тиск через НАДМІРНУ красу
- Bordello + casino + palace = декаданс влади

**Consistency правила:**
- Завжди МАСИВНА люстра домінує
- Червоний + золотий = основна палітра
- Папуга в позолоченій клітці
- Карта світу в золотій рамі
- Паркет дзеркально блищить
- Оксамит скрізь (м'який, темний червоний)
- Мундштук на червоному оксамиті (signature Марго)

**Символізм:**
- Розкіш = влада
- Позолота = імперська спадщина
- Червоний оксамит = bordello + кров + влада
- Карта = глобальна мережа
- Жако = спостерігач, що запам'ятовує все

   - Одяг персонажів (Марго = темний шовк, Інженер = дірявий светр)
