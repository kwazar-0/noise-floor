# Noise Floor — GitHub Pages

Это публичная версия трилогии для GitHub Pages.

## Структура

- `index.html` — главная страница (пролог цикла + навигация)
- `01-orden-lipok/` — Том 1 (1992–1993)
- `02-nulevoj-blok/` — Том 2 (2007–2009)
- `03-nizhe-urovnya-shuma/` — Том 3 (2022)
- `style.css` — минимальное оформление

## Развёртывание

1. Push в `main` branch
2. Settings → Pages → Source: `main` branch, `/docs` folder
3. Сайт будет доступен по адресу: `https://kwazar-0.github.io/noise-floor/`

## Обновление контента

Текстовые файлы находятся в `roman/*/text/`. Для публикации на GitHub Pages нужно конвертировать их в HTML и поместить в соответствующие папки `docs/`.
