# ANTI-AI REWRITE GUIDE
## Керівництво для переробки роману з видаленням AI-маркерів

**Мета:** Зламати AI-гладкість, додати суржик, створити "людський" текст.

---

## 1. КЛЮЧОВІ ПРОБЛЕМИ AI-ТЕКСТУ

### ❌ Що видає AI:
- **Гладкі триади**: "Х, Y, Z" (три описи підряд з однаковою структурою)
- **Передбачувані описи**: "лицо спокойное, глаза без эмоций, руки на столе"
- **Рівномірний ритм**: всі абзаци однакової довжини
- **Занадто багато прикметників**: "темний, старий, потертый"
- **Пояснення всього**: AI завжди пояснює, що відбувається

## 2. ANTI-AI ТЕХНІКИ

### ✅ ТЕХНІКА 1: Зламати триади

**Було (AI):**
```
Корбан масивний, сорок два, тіло міцне. Костюм темний, дорогий, але не 
показний. Обручка, печатка. Годинник золотий, але не «Ролекс» — скромніше.
```

**Стало (Людина):**
```
Корбан масивний, сорок два. Костюм темний (дорогий, але не показний). Обручка,
печатка. Годинник золотий, не «Ролекс» — скромніше. Обличчя широке, єврейське.
```

**Правило:** Змішуй довжину речень. Не три підряд — два, потім одне, потім чотири.

---

### ✅ ТЕХНІКА 2: Рваний ритм

**Було (AI):**
```
Оля відповіла теж російською. Акцент київський, без інтонацій. Корбан кивнув. 
Запалив. Вона теж. Дим пішов у різні боки.
```

**Стало (Людина):**
```
Оля відповіла теж російською. Акцент київський.

— Вена хороша для разговора.

Корбан кивнув. Запалив. Вона теж. Дим у різні боки.
```

**Правило:** Вставляй короткі удари. Обривай речення. Не завжди закінчуй думку.

---

### ✅ ТЕХНІКА 3: Несподівані деталі

**Було (AI):**
```
На стіні крейда: «не курити».
```

**Стало (Людина):**
```
На стіні крейда: «не курити» (закреслено двічі).
```

**Правило:** Додай ОДНУ несподівану деталь на сцену. Не більше! Іржа, тріщина, плями, запах.

---

### ✅ ТЕХНІКА 4: СУРЖИК (Ukrainian-Russian mix)

**Правила суржика 90-х Київ:**

#### Narrative (оповідь):
- **Микс Ukrainian + Russian** природно
- Не перемикайся посередині речення без причини
- Українські слова для побуту: хвіртка, двір, сходи
- Російські для "офіційного": контора, документы

#### Діалоги:
- **Повний суржик** як говорили насправді
- Особливо старше покоління (Ніна, Сідий)
- Молодші можуть бути більш російськомовні (Оля)

**Приклади суржику:**

```
✅ ДОБРЕ:
"Він говорив російською. Акцент дніпровський."
"Двір позаду: білизна на іржавій мотузці."
"— Слухай. У центрі контора. Секретарша треба."

❌ ПОГАНО (занадто "правильно"):
"Він говорив російською мовою. Акцент був дніпровський."
"Двір знаходився позаду: білизна висіла на іржавій мотузці."
```

---

### ✅ ТЕХНІКА 5: Стиснення

**Було (AI - багатослівно):**
```
Саня протянув руку к вороту — проверить, не пусто — и Иса глянул так, 
что рука вернулась в карман, обожжённая не ею, чужим счётом.
```

**Стало (Людина - стисло):**
```
Саня простягнув руку до комі ра (перевірити, не порожньо) — Іса глянув 
так, що рука повернулась у кишеню (обпечена не нею, чужим рахунком).
```

**Правило:** Якщо можна в дужки — в дужки. Довгі вставні конструкції → короткі.

---

### ✅ ТЕХНІКА 6: Видали пояснення

**Було (AI пояснює):**
```
Он усмехнулся. Оцінив чесність. Це було знаком поваги між ними.
```

**Стало (Людина НЕ пояснює):**
```
Кивнув. Оцінив.
```

**Правило:** Якщо читач розумний — він сам зрозуміє. НЕ пояснюй емоції, мотивації, підтексти.

## 3. CHECKLIST ДЛЯ КОЖНОЇ ГЛАВИ

Пройдись по кожній главі:

- [ ] **Знайди триади** (три описи підряд) → зламай їх
- [ ] **Знайди рівномірні абзаци** → зроби один короткий, один довгий
- [ ] **Знайди пояснення** ("он понял", "она почувствовала") → видали
- [ ] **Додай 2-3 несподівані деталі** (іржа, тріщина, запах)
- [ ] **Перевір діалоги** → мають бути суржиком
- [ ] **Перевір narrative** → суржик Ukrainian+Russian
- [ ] **Скороти багатослівні місця** → в дужки або видалити
- [ ] **Короткі удари** → додай 3-5 на главу

## 4. BEFORE/AFTER ПРИКЛАДИ З ПЕРЕРОБЛЕНИХ ГЛАВ

### Приклад 1: Prolog

**БУЛО (AI):**
```
Три года назад Белое братство собрало десять тысяч на Софийской площади — 
ждали конца света, конец не пришёл, Марию Дэви Христос увезли. Остались 
«точки». Их никто не считал. Квартиры, подвалы, общаги.
```

**СТАЛО (Людина + суржик):**
```
Три роки тому Біле братство. Десять тисяч на Софійській — чекали кінця 
світу. Кінець не прийшов, Марію Деві Христос забрали на швидкій (кажуть, 
вона не чинила опору, тільки сміялась). Але «точки» залишились. Ніхто не 
рахував. Квартири на Подолі, підвали біля метро, гуртожиток КПІ.
```

**Зміни:**
- Короткі речення замість довгих
- Додана несподівана деталь (вона сміялась)
- Конкретика (Поділ, КПІ)
- Суржик

### Приклад 2: Glava 1

**БУЛО (AI):**
```
Соседка — косичка, родинка над губой — сидела на кровати, красила ногти. 
Лак красный, пах ацетоном. Дула на пальцы, не поднимая глаз.
```

**СТАЛО (Людина + суржик):**
```
Сусідка (косичка, родимка над губою) сиділа на ліжку, фарбувала нігті. Лак 
червоний, ацетоном пахло. Дмухала на пальці. Не піднімала очей.
```

**Зміни:**
- Дужки замість тире (стисло)
- Суржик narrative
- Короткі речення

### Приклад 3: Glava 3 (флірт Корбан-Марго)

**БУЛО (AI - загроза):**
```
— А якщо я скажу ні? — спитала вона.

Корбан не усміхнувся. Відповів серйозно, але без погроз.

— Тоді я шукатиму інші канали. Ти шукатимеш інші заводи.
```

**СТАЛО (Людина - флірт):**
```
— А если я скажу нет? — спитала вона. Не виклик. Цікавість.

Корбан посміхнувся. Широко. Майже з задоволенням від питання.

— Тогда я буду искать другие каналы. Ты будешь искать другие заводы. — 
Нахилився ближче, голос тихіше, майже в вухо. — Но я уже знаю, что ты 
умная. А умные люди не теряют время на то, что можно решить за один 
разговор. Особенно в Вене. Особенно с хорошим вином после.
```

**Зміни:**
- Додано мікро-жести (посміхнувся широко)
- Флірт замість загрози
- Несподівана деталь (вино після)

## 5. REGEX PATTERNS ДЛЯ АВТОЗАМІН

### Знайти триади (для ручної правки):
```regex
([А-ЯЁІЇЄҐа-яёіїєґ]+[,\.] ){2}[А-ЯЁІЇЄҐа-яёіїєґ]+\.
```

### Знайти пояснення емоцій:
```regex
(понял|поняла|почувствовал|почувствовала|осознал|осознала)
```

### Знайти занадто гладкі описи:
```regex
^[А-ЯЁ][а-яё]+ [а-яё]+, [а-яё]+ [а-яё]+, [а-яё]+ [а-яё]+\.$
```

## 9. ЩО НЕ РОБИТИ

❌ **НЕ додавай багато деталей** — 2-3 на сцену, не більше  
❌ **НЕ перемикайся між мовами без причини** — суржик має бути природним  
❌ **НЕ пояснюй все** — читач розумний  
❌ **НЕ роби всі речення короткими** — микс довгих і коротких  
❌ **НЕ видаляй атмосферу** — тільки пояснення
